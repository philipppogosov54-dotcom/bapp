## 📖 Что это?

**BeautyScore** — это веб-приложение, которое помогает людям выбирать косметику на основе их индивидуальных особенностей. Используя искусственный интеллект, приложение анализирует составы продуктов и даёт персональные рекомендации.

### 🎯 Главная идея
Вместо того чтобы читать непонятные составы и гадать, подойдёт ли продукт, BeautyScore:
- Анализирует состав
- Оценивает безопасность
- Подбирает подходящие средства
- Объясняет простым языком

## 🚀 Быстрый старт

### Требования
- Node.js 20+
- PostgreSQL 15
- Redis 7
- pnpm

### Установка

```bash
# Клонирование
git clone https://github.com/philipppogosov54-dotcom/bapp.git
cd beautyscore

# Установка зависимостей
pnpm install

# Запуск Docker (PostgreSQL + Redis)
docker-compose up -d

# Миграции и seed базы данных
cd apps/api
npx prisma migrate deploy
npx prisma db seed

# Запуск backend (в одном терминале)
cd ../..
pnpm dev --filter=api

# Запуск frontend (в другом терминале)
pnpm dev --filter=web
```

### Доступ
- **Frontend:** http://localhost:3000
- **Backend API:** http://localhost:3001
- **Тестовый пользователь:** `test@beautyscore.ru` / `test123456`
